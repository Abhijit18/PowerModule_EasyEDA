# Immutable source evidence

`original/` is the owner's uploaded schematic and Gerber ZIP. `rev-b/` are assistant-produced draft EasyEDA Standard and KiCad artifacts **not independently verified inside EasyEDA Pro**. These are historical references, not engineering release files; do not alter their contents. New editable designs belong in `hardware/rev-c/` and in a separate owner-approved EasyEDA Pro project. Source files can contain errors and require datasheet + native net/readback validation. These files may be proprietary; review sharing before pushing to a public repository.
